# ທຳນຽມສັນຍາເຊົ່າ ແລະ Checklist ຄຳຖາມເຈົ້າຂອງ (Lease Norms & Landlord Checklist — Laos)

> ຄົ້ນຄວ້າ 2026-11-13. **ລະດັບຄວາມໝັ້ນໃຈ: ປານກາງ** — ແຫຼ່ງເປັນຄູ່ມືຊາວຕ່າງປະເທດ, ບໍລິສັດກົດໝາຍລາວ ແລະ ປະກາດເຊົ່າ (ສ່ວນຫຼາຍວຽງຈັນ). ກ່ອນເຊັນ ຄວນໃຫ້ທະນາຍຄວາມລາວກວດສັນຍາ.

## 1. ທຳນຽມທົ່ວໄປ (Common practice)

| ເລື່ອງ | ທຳນຽມ |
|---|---|
| ເງິນຈອງ (holding deposit) | ປົກກະຕິ 1 ເດືອນ, ຫັກເປັນຄ່າເຊົ່າເດືອນທຳອິດ. ຖ້າຜູ້ເຊົ່າຖອນຕົວ ເຈົ້າຂອງມັກບໍ່ຄືນ ເວັ້ນແຕ່ຂຽນໄວ້ໃນສັນຍາ |
| ເງິນມັດຈຳ (security deposit) | ມັກຮຽກເກັບ ເມື່ອຈ່າຍລາຍເດືອນ |
| ຈ່າຍລ່ວງໜ້າ | ຈ່າຍລ່ວງໜ້າ 6 ເດືອນ ຫາ 1 ປີ ເປັນເລື່ອງປົກກະຕິ ແລະ ມັກບໍ່ຕ້ອງວາງມັດຈຳ; ໃຊ້ເປັນຂໍ້ຕໍ່ລອງຫຼຸດລາຄາໄດ້ |
| ການຈ່າຍ | ມັກຈ່າຍເງິນສົດ → ຕ້ອງເອົາໃບຮັບເງິນທຸກຄັ້ງ |
| ລາຄາ | ປະກາດມັກບອກວ່າ "ຕໍ່ລອງໄດ້ ຕາມໄລຍະສັນຍາ ແລະ ການຈ່າຍລ່ວງໜ້າ"; ເຮືອນແຖວ (shophouse) ຢູ່ລາວ ປະມານ 500–3,000 USD/ເດືອນ |
| ຄົນຕ່າງປະເທດ | ຄົນຕ່າງປະເທດເປັນເຈົ້າຂອງທີ່ດິນບໍ່ໄດ້; ບໍ່ພົບຂໍ້ມູນຊັດເຈນເລື່ອງສິດເຊົ່າການຄ້າຂອງບຸກຄົນຕ່າງປະເທດ → ຖາມທະນາຍ |

## 2. ສິ່ງທີ່ສັນຍາຄວນມີ (Lease must include)

- ຄ່າເຊົ່າ, ສະກຸນເງິນ, ກຳນົດຈ່າຍ, ການຂຶ້ນລາຄາແຕ່ລະປີ (ຈັກ %)
- ເງິນມັດຈຳ: ຈຳນວນ ແລະ ເງື່ອນໄຂຄືນ
- ອາຍຸສັນຍາ + ສິດຕໍ່ສັນຍາ (ແນະນຳ 3+3 ປີ ຫຼື ຍາວກວ່າ ເພື່ອໃຫ້ຄືນທຶນຕົກແຕ່ງ)
- ເງື່ອນໄຂຍົກເລີກ ແລະ **ຄືນເງິນລ່ວງໜ້າ ກໍລະນີຍົກເລີກກ່ອນກຳນົດ**
- ສິດດັດແປງອາຄານ ແລະ ຜູ້ຮັບຜິດຊອບຂໍອະນຸຍາດ; ເມື່ອໝົດສັນຍາ ຕ້ອງຄືນສະພາບເດີມ ຫຼື ບໍ່
- ໃຜຈ່າຍ: ພາສີທີ່ດິນ/ອາກອນຄ່າເຊົ່າ, ສ້ອມແປງໂຄງສ້າງ/ຫຼັງຄາ, ຄ່ານ້ຳ-ໄຟ
- ສິດໃຫ້ເຊົ່າຊ່ວງ / ໂອນສັນຍາ (ຖ້າຂາຍກິດຈະການ)
- ໄລຍະຟຣີຄ່າເຊົ່າ (rent-free fit-out period)
- ເງື່ອນໄຂບັງຄັບກ່ອນ: ສັນຍາມີຜົນເມື່ອໄດ້ໃບອະນຸຍາດທຸລະກິດ ແລະ ສ້ອມແປງ
- ລາຍການຊັບສິນ/ເຟີນີເຈີ ທີ່ສົ່ງມອບ + ຮູບສະພາບວັນສົ່ງມອບ

## 3. Checklist ຄຳຖາມເຈົ້າຂອງ (Ask the landlord)

**ເອກະສານ ແລະ ສິດ**
- [ ] ໃບຕາດິນ/ທະບຽນເຮືອນ ເປັນຊື່ໃຜ? ຜູ້ໃຫ້ເຊົ່າມີສິດ ຫຼື ເປັນນາຍໜ້າ?
- [ ] ອາຄານຕິດຈຳນອງທະນາຄານ ຫຼື ມີຂໍ້ຂັດແຍ່ງ ບໍ?

**ເງິນ**
- [ ] ລາຄາສຸດທ້າຍ ຖ້າຈ່າຍລ່ວງໜ້າ 6 ເດືອນ / 1 ປີ?
- [ ] ເງິນມັດຈຳຈັກເດືອນ? ຄືນເມື່ອໃດ?
- [ ] ຂຶ້ນລາຄາແຕ່ລະປີ ບໍ? ຈັກ %?
- [ ] ລາຄາລວມອາກອນຄ່າເຊົ່າ ແລ້ວ ຫຼື ບໍ່?
- [ ] ມີໄລຍະຟຣີຄ່າເຊົ່າລະຫວ່າງສ້ອມແປງ ບໍ? ຈັກເດືອນ?

**ອາຍຸສັນຍາ**
- [ ] ສັນຍາຕ່ຳສຸດ/ສູງສຸດ ຈັກປີ? ຕໍ່ໄດ້ ບໍ?
- [ ] ຍົກເລີກກ່ອນກຳນົດ ແນວໃດ? ເງິນລ່ວງໜ້າຄືນ ບໍ?

**ອາຄານ ແລະ ລະບົບ**
- [ ] ຂະໜາດພື້ນທີ່ໃຊ້ສອຍແຕ່ລະຊັ້ນ?
- [ ] ມິເຕີໄຟ/ນ້ຳ ແຍກ ບໍ? ໄຟຈັກເຟດ/ແອມ (ເຄື່ອງກາເຟ + ເຕົາອົບ + ແອ)?
- [ ] ຫ້ອງນ້ຳ, ທໍ່ນ້ຳເສຍ, ບໍ່ເກຣອະ (grease trap) ມີ ບໍ?
- [ ] ຫຼັງຄາຮົ່ວ ບໍ? ນ້ຳຖ້ວມ ບໍ (ລະດູຝົນ)?
- [ ] ເຟີນີເຈີເກົ່າ ຢູ່ຕໍ່ ຫຼື ເອົາອອກ?

**ການດັດແປງ ແລະ ການໃຊ້ງານ**
- [ ] ອະນຸຍາດໃຫ້ດັດແປງຫຍັງໄດ້ແດ່? ໃຜຂໍອະນຸຍາດຫໍມໍລະດົກ?
- [ ] ໝົດສັນຍາ ຕ້ອງຄືນສະພາບເດີມ ບໍ?
- [ ] ເປີດຮ້ານກາເຟ/ອາຫານ, ຂາຍເຫຼົ້າ-ເບຍ, ເປີດເພງ ໄດ້ ບໍ? ເວລາເປີດ-ປິດ?
- [ ] ຕິດປ້າຍໜ້າຮ້ານ ໄດ້ ບໍ?
- [ ] ຜູ້ເຊົ່າລັອກຂ້າງໆ ເຮັດທຸລະກິດຫຍັງ? ມີພື້ນທີ່ໃຊ້ຮ່ວມ ບໍ?
- [ ] ໃຫ້ເຊົ່າຊ່ວງ ຫຼື ໂອນສັນຍາ ໄດ້ ບໍ?
