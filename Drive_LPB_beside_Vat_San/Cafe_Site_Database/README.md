## ລະຫັດສະຖານທີ່ (Site ID convention)

`<CITY>-<NNN>_<Street>_<Unit>` — ຕົວຢ່າງ `LPB-001_Sakkaline_Right-Unit`
- `CITY`: LPB = ຫຼວງພະບາງ (Luang Prabang), VTE = ວຽງຈັນ (Vientiane)...
- `NNN`: ລຳດັບ 001, 002, ... (ບໍ່ໃຊ້ເລກຊ້ຳ, ເຖິງສະຖານທີ່ຈະຖືກຕັດອອກກໍ່ຕາມ)
- `Street` / `Unit`: ຊື່ຖະໜົນ ແລະ ລັອກ ເປັນພາສາອັງກິດ, ບໍ່ມີຍະຫວ່າງ

## ກົດໃນການບັນທຶກ (Data rules)

1. ແຍກ **ຂໍ້ເທັດຈິງທີ່ຢືນຢັນແລ້ວ** ກັບ **ຂໍ້ສັນນິຖານ**: ໝາຍ `[ຢືນຢັນແລ້ວ / confirmed]`, `[ຄາດຄະເນ / estimated]` ຫຼື `[ຕ້ອງຢືນຢັນ / to confirm]`.
2. ບອກແຫຼ່ງທີ່ມາ (ທີມສຳຫຼວດ, ເຈົ້າຂອງ, OpenStreetMap, ເວັບໄຊ) ແລະ ວັນທີ.
3. ເງິນເປັນ USD ເວັ້ນແຕ່ຈະບອກໄວ້. ໄລຍະທາງເປັນເສັ້ນຊື່ (straight-line) ເວັ້ນແຕ່ຈະບອກໄວ້.
4. ຮູບບໍ່ເກັບໃນນີ້. ໄຟລ໌ສະຖານທີ່ມີທາງໄປຫາຮູບ ແລະ ຄຳອະທິບາຍເປັນຕົວໜັງສື.

## ວິທີເພີ່ມສະຖານທີ່ໃໝ່ (How to add a site)

1. ກຳນົດ site_id ຖັດໄປ.
2. ສຳເນົາ `sites/LPB-001_Sakkaline_Right-Unit.md` ເປັນແມ່ແບບ ແລ້ວປ່ຽນຂໍ້ມູນ (ຮັກສາຫົວຂໍ້ ແລະ ລຳດັບໄວ້ຄືເກົ່າ).
3. ເພີ່ມ 1 ແຖວໃນ `sites_index.csv`.
4. ຖ້າພົບກົດລະບຽບ/ທຳນຽມໃໝ່ທີ່ໃຊ້ໄດ້ທົ່ວໄປ, ເພີ່ມໃສ່ `shared/` ບໍ່ແມ່ນໃສ່ໄຟລ໌ສະຖານທີ່.
